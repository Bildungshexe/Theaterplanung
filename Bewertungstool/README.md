# Bewertungstool (offline)

Eine einzige HTML-Datei zum Bewerten mündlicher Leistungen, offline und ohne Installation:
Songvortrag Spanisch, Lesen (Deutsch, Spanisch, andere Fremdsprache), Gedichtvortrag (Deutsch, Spanisch, andere Fremdsprache), Referat (Deutsch, Geschichte, Politik und Gesellschaft, Spanisch/Fremdsprache, anderes Fach), Abfrage (Fachwissen, Vokabular, Grammatik, Textkenntnis), Unterrichtsbeitrag und Theater. Dazu kommen Klassenverwaltung, frei eingetragene Noten (Referat, Mitarbeit …), Übersichten pro Schüler/in und Klasse, Druck/PDF (A4 quer) und CSV-Export.

## Herunterladen
1. Datei `Bewertungstool.html` in diesem Ordner anklicken.
2. Rechts oben auf das Download-Symbol („Download raw file“) tippen.
3. Die heruntergeladene Datei im Browser öffnen (Chrome oder Edge empfohlen).

## Wichtig
- Die Daten (Klassen, Noten) bleiben nur im Browser des Geräts gespeichert, nicht auf GitHub.
- Regelmäßig unter **Einstellungen → Alle Daten sichern** eine Sicherungsdatei anlegen; damit lassen sich die Daten auch auf ein anderes Gerät übertragen.
- Ältere Sicherungen aus „Songvortrag_Bewertung_Offline“ oder „Bewertung_Offline“ lassen sich unter **Einstellungen → Ältere Sicherung importieren** übernehmen; Sicherungen des „Mündliche-Noten-Tools“ direkt mit **Sicherung laden**.
- Kriterien, Gewichtungen und Punktwerte sind Vorschläge; die Quellen stehen im Tool unter „Einstellungen“.
