Achtung: Dieser Browser erlaubt hier kein Speichern (z. B. privates Fenster oder eingeschränkte Datei-Ansicht). Die Eingaben gehen beim Schließen verloren. Bitte regelmäßig „Sichern“ benutzen oder die Datei direkt in Chrome, Edge, Firefox oder Safari öffnen.

So funktioniert es

  1. Einrichtung: Fach, Kriterien, Schwerpunkt und Punkte wählen. Das geht jederzeit erneut über „Einrichtung“.
  2. Bogen anlegen: Mit „+ Schüler/in“ einen neuen Bogen anlegen, Name und Thema eintragen. Mit ◀ ▶ oder der Auswahlliste zwischen den Bögen wechseln.
  3. Bewerten: Pro Kriterium die passende Beschreibung antippen. Nochmal antippen hebt die Auswahl auf. Mit − und + den Wert innerhalb der Stufe fein einstellen.
  4. Note: Sie erscheint automatisch, sobald alle Kriterien bewertet sind.
  5. Drucken / PDF: Im Druckfenster „Als PDF speichern“ oder einen Drucker wählen, A4 quer, Ränder „Keine“, „Hintergrundgrafiken“ einschalten. „Leerer Bogen“ druckt eine Vorlage zum Ausfüllen von Hand.
  6. Übersicht / CSV: „Übersicht“ zeigt alle Ergebnisse. „Tabelle (CSV)“ erzeugt eine Datei für Excel oder LibreOffice.

Datenschutz

Das Programm arbeitet vollständig offline und ist technisch so gesperrt, dass es keine Verbindung ins Internet aufbauen kann. Alle Eingaben bleiben ausschließlich im Browser dieses Geräts. Sicherungs- und CSV-Dateien enthalten personenbezogene Daten. Behandeln Sie sie wie Notenlisten: nur auf dienstlichen oder verschlüsselten Geräten speichern. Löschen Sie die Daten am Schuljahresende über „Einrichtung“ → „Alle Daten löschen“. Auf gemeinsam genutzten Geräten sollten Sie nach der Arbeit sichern und dann löschen.
