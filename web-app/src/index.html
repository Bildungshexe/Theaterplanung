Auf dem iPad installieren

  1. Diese Seite in Safari öffnen (nicht in einer anderen App).
  2. Auf das Teilen-Symbol (Quadrat mit Pfeil nach oben) tippen.
  3. „Zum Home-Bildschirm“ wählen und „Hinzufügen“ tippen.
  4. Ab jetzt die Tools immer über das neue Symbol auf dem Home-Bildschirm öffnen. Dann laufen sie auch ohne Internet, und die Daten bleiben dauerhaft gespeichert.

Wichtig: Daten, die in Safari eingegeben werden, und Daten in der Home-Bildschirm-App sind getrennt. Bitte nur mit der App vom Home-Bildschirm arbeiten. Regelmäßig „Sichern“ benutzen: Auf dem iPad öffnet sich dann „Teilen“ – dort „In Dateien sichern“ wählen.

Datenschutz

Die Programme werden nur einmal von dieser Adresse geladen und dann auf dem Gerät gespeichert. Bewertungsdaten werden nie übertragen: Die Seiten sind technisch so gesperrt, dass sie keine Verbindungen aufbauen können. Gespeichert wird ausschließlich im Speicher dieser App auf diesem Gerät. Für zusätzlichen Schutz in jedem Tool unter „Einrichtung“ einen Passwortschutz einrichten.
